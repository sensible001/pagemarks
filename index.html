        How Pagemarks works

        Link health colors
        • Working: the page opened normally.
        • Moved: the address now leads somewhere else. Use Update link, unless it lands on a home or sign-in page (then the page is probably gone).
        • Broken: missing, server error, or refused to everyone. Or you marked it broken yourself.
        • Couldn't check: the site blocks automated checks or needs a sign-in. Usually fine. If it won't open for you either, use Mark as broken.
        • Not checked yet: new, or its address was just changed.
        The nightly link check
        • Runs every night, usually between 2:00 AM and 3:30 AM Eastern Time (ET). To run it now: GitHub → Actions → Check links → Run workflow.
        • A page must fail two checks in a row before it turns red, so a short outage isn't flagged.
        • A plain “403 Forbidden” counts as broken. Bot-protection screens stay gray.
        • Your Mark as broken always wins over the checker.
        Organizing
        • Organize shows the tools; Done (or Esc) returns to the calm view.
        • Folders stay until you delete them. Delete folder only appears when a folder is empty.
        • A folder shows its own Pagemarks, with sub-folders as rows on top. Sidebar counts include sub-folders.
        • Move things by dragging onto a folder, or with Move to folder…
        • Tidy up files Pagemarks with no folder, one at a time, with suggested folders first.
        Home, Star and Pin
        • ☆ Star a Pagemark to put it on Home. Home shows your starred Pagemarks grouped by folder; click a folder's name to open it.
        • Click the ★ again to take it off Home. It stays in its folder.
        • Pin (in Organize) keeps a Pagemark at the top of its folder, above the sort order. Pinned ones show a small pin.
        • They're separate: Star is for Home, Pin is for order inside a folder. A Pagemark can be both.
        The Librarian
        • The Librarian is Pagemarks' AI helper. It suggests a folder for each Pagemark that has none. The suggestions wait in Tidy up, where you can accept them one by one or all at once, and change anything later.
        • Each time you ask, the Librarian looks at up to 2,000 Pagemarks. It usually takes about 15 minutes, and you can keep using Pagemarks or close it while it works.
        • The owner decides how many times each person can ask.
        • Suggestions are made with the help of AI. Only the titles and web addresses of Pagemarks without a folder are sent.

        Named in memory of Bill, a librarian and friend, whose idea of checking for broken links helped start Pagemarks.

        Searching
        • Search looks through titles, web addresses, descriptions, notes, folders and tags. Every word you type must match.
        • On Home, it searches all your Pagemarks. In a folder, it searches that folder and its sub-folders.
        • Clicking Home or the Pagemarks logo clears the search. Clicking a folder keeps it, so you can narrow the results.
        • To clear it any time, click ✕ in the search box or press Esc.
        Content rules
        • Pagemarks doesn't allow adult, violent, hateful or harmful content.
        • Each Pagemark is checked when it's saved or imported: a short list of blocked sites, a word filter (titles, notes, tags, folder names, web addresses) and Cloudflare's family-safe check for adult and malware sites. Only the site name is sent to Cloudflare.
        • If something isn't allowed, it simply isn't saved. Nobody is blocked or penalized automatically.
        • Only a count of refused saves is kept for each account, never which site or text was refused. The owner can see the counts in the Invite list.
        Only you see this

        To test the content rules, add one of these. Each should be refused and add 1 to your count in the Invite list.

        • blocked-test.pagemarks.com tests Pagemarks' own list
        • malware.testcategory.com tests Cloudflare's malware check
        • nudity.testcategory.com tests Cloudflare's adult-content check

        Browser button

        The Pagemarks button saves the page you're on in one click: click it, or press Alt+Shift+P, then Save. It works in Chrome, Edge, Brave, Opera and Vivaldi on a computer.

        Import favorites

        In Chrome or Edge, export your favorites as an HTML file, then choose it here. Each one becomes a Pagemark. Duplicates are skipped.

        Folder suggestions file Only you see this

        Load a suggestions file. Each Pagemark with no folder gets its suggested folder ready to accept in Tidy up.

        Export

        Take your Pagemarks anywhere. The HTML file imports into any browser (Edge, Chrome, Firefox, Safari) with your folders and order; starred ones also go in a “★ Home” folder, and Firefox keeps tags and notes too. JSON is a complete backup of everything.
